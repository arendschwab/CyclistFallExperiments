# CyclistFallExperiments

Processed data from the Cyclist Fall Experiments 
done in the period 3 jan - 22 feb 2022 at Delft University of Technology 
by Marco M. Reijne and Arend L. Schwab

For description of experiments etc. see Ch3 "A Model Based on Cyclist Fall ExperimentsWhich Predicts The Maximum
Allowable Handlebar Disturbance From Which A Cyclist Can Recover Balance" of Marco Reijne's PhD thesis:
> Reijne, M. M. "Modeling and Evaluation of Cyclist Fall Prevention Interventions: A Proactive Cycling Safety Approach." PhD diss., Doctoral Dissertation. Delft University of Technology. Delft, Netherlands. doi: 10.4233/uuid: ada397a7-0c55-4284-9133-3c5ea515ea67, 2025.
attached as [reijne2025modeling.pdf](https://github.com/arendschwab/CyclistFallExperiments/blob/main/reijne2025modeling.pdf)

Most of the contents of Ch3 found it's way in the scientific publication:
> Reijne, M.M., van der Meulen, F.H., van der Helm, F.C. and Schwab, A.L., 2025. A model based on cyclist fall experiments which predicts the maximum allowable handlebar disturbance from which a cyclist can recover balance. Accident Analysis & Prevention, 221, p.108159.
attached as [reijne2025model.pdf](https://github.com/arendschwab/CyclistFallExperiments/blob/main/reijne2025model.pdf)

The Data is stored in a Matlab file `Datav3.mat` (2.1 GB) This large file can be found under the `Releases` in the right pane of the repository page and downloaded from there. Start by selecting `<> Code` in the top bar under the repository name bar, or follow this link [Datav3.mat](https://github.com/arendschwab/CyclistFallExperiments/releases/tag/v3).

Data description for the Matlab file `Datav3.mat` (2.1 GB) can be found in [DataDictionaryDatav3.txt](https://github.com/arendschwab/CyclistFallExperiments/blob/main/DataDictionaryDatav3.txt)
